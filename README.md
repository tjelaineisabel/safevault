Safe-Vault: Secure Document Organizer

Project Description:
A full-stack web application designed to securely store, organize, and track personal and important documents with expiration monitoring, administrative controls, and user management.

Tech Stack:
Frontend: HTML5, CSS3, Bootstrap 5, JavaScript
Backend: PHP
Database: MySQL

Deployment Steps
1. Clone the repository
2. Import the database SQL file into the MySQL server (named `dash`).
3. Update database credentials in `db.php`.
4. Run the project on a local server (XAMPP) or deploy to a live PHP hosting provider.
